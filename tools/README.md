# tools - this lab's own programs (Rust)

One crate per tool: `walleye-rootfs` (the Alpine rootfs image), `walleye-ramroot` (the Alpine-in-RAM boot
image), `walleye-stripes` (the display stripe drawer), `walleye-reboot` (reboot(2) RESTART2 with `bootloader`, which busybox drops; `build/build-reboot-bin.sh OUT` makes the static aarch64 file, declared by sha256 in `[images.walleye-reboot]`, that the stage 1 way back pushes to the phone's /tmp), `walleye-nfc-up` (netlink NFC_CMD_DEV_UP: opens nfc0 and prints the kernel's answer; `build/build-nfc-up-bin.sh OUT` makes the static aarch64 file declared in `[images.walleye-nfc-up]`, packed in the NFC ramdisk as /bin/walleye-nfc-up), `walleye-cmdline-budget` (every `[images.*.recipe]` command line within the 160-character header budget; an image over it stands in tests/host/cmdline-over-budget.toml only while it is NOT-TO-BOOT; run by `make land-check`), `walleye-sources` (the gate that every tests/host script names its source in tests/host/SOURCES.toml: a research row, a source row, a file, or why not yet).
